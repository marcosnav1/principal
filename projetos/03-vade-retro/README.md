# Vade retro — edição (Shorts 9:16, 56,3 s)

`editar.py` monta o vídeo a partir de `clips/01..06.mp4` (Veo), `narracao.mp3` (ElevenLabs) e
`fonts/` (Cinzel 800 via npm @fontsource/cinzel@5.0.8). Ordem dos clipes: sombra/casa, mulher na cama,
túmulo, arcanjo, espada/serpente, Jesus.

Decisões: corte do defeito inicial do clipe 3 (0–1,3 s); fala de Jesus duplicada na narração
(42,6–55,4 s) removida — Jesus usa a voz do próprio clipe 6 (sincronia labial); sussurro final
reposicionado; desenho sonoro original (drone A=432, nota de metal + sub, 4 tambores, silêncio
absoluto de 0,5 s, hum quente); legendas Cinzel condensada, centro-inferior (bottom 15% livre),
frase 5 em dourado; loudness -14 LUFS.
